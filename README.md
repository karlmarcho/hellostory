# hellostory
## Drift Sector

`drift-sector/index.html` is a single-file, turn-based sci-fi strategy game on hex tiles, played against an AI. Open it in a browser to play.

- **Win** by any of: 20 relay points (park ships on relay crystals), 1200 total yield, or destroying the enemy Command Citadel.
- **Economy:** colonies claim territory. Each hex yields energy, ore or data, and extractors double or triple that yield. Research spends data.
- **Terrain:** asteroid cover, nebulae that hide ships, gravity wells, star-lit hexes.
- **Combat:** d6 dice with return fire. Fog of war, and Easy, Normal and Hard AI.
